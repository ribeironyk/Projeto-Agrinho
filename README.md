# IA na Agricultura — Agrinho 2026

## Descrição do Projeto

Este site apresenta uma pesquisa aprofundada sobre a aplicação da Inteligência Artificial na agricultura, desenvolvido para o **Concurso Agrinho 2026** na categoria Programação. O projeto explora como tecnologias como machine learning, deep learning, visão computacional e sensoriamento remoto estão transformando o agronegócio e contribuindo para um futuro mais sustentável.

## Objetivo do Tema Agrinho

O tema central desta pesquisa é demonstrar como a Inteligência Artificial pode ser uma ferramenta poderosa para enfrentar os desafios da agricultura contemporânea — aumentando a produtividade, reduzindo o consumo de recursos naturais, detectando doenças em plantas com precisão e promovendo a inclusão digital no campo. O conteúdo é baseado em revisões sistemáticas e estudos científicos publicados entre 2024 e 2026.

## Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível
- **CSS3** — Layouts modernos com Flexbox e CSS Grid, animações complexas via `@keyframes`, transições suaves, tema escuro e responsividade completa via Media Queries
- **JavaScript (Vanilla)** — Manipulação funcional do DOM, sistema de abas interativas, canvas de partículas animadas, contadores dinâmicos, controle de tema, ajuste de fonte e validação de formulários

## Instruções de Uso

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
3. Navegue pelas seções utilizando o menu superior ou rolando a página.
4. Explore as funcionalidades interativas:
   - **Tema escuro/claro:** clique no ícone de lua/sol no cabeçalho.
   - **Tamanho da fonte:** use os botões "A-" e "A+" para ajustar a legibilidade.
   - **Aplicações:** clique nas abas para alternar entre os temas de Predição, Doenças, Privacidade e Precisão.
   - **Ordenação de referências:** utilize o menu de seleção para ordenar as referências por ano.
   - **Newsletter:** preencha o formulário no rodapé para simular uma inscrição.

> Não é necessário nenhum servidor ou instalação adicional. O projeto funciona 100% no lado do cliente.
